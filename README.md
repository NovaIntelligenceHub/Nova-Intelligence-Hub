# Nova AI V3 — Pharmaceutical Learning Website

## Included
- Text-only welcome screen: “Welcome! Study Smarter with Nova”
- Responsive dashboard
- 18 Pharmacovigilance modules and 20 Regulatory Affairs modules
- Topic explanations, topic outlines, fictional educational examples and model-answer knowledge checks
- ICSR, CTD and gap-review practice exercises
- Fresher interview preparation
- Searchable pharmaceutical glossary
- Browser-local lesson progress tracking
- Offline curated Nova Tutor demonstration

## Important limitations
This is a functional front-end learning prototype. Nova Tutor uses built-in content and is **not connected to a live AI model**. It does not generate live AI answers or images, monitor regulatory websites, validate real ICSR cases, or validate regulatory submissions. Those capabilities require a secure backend and configured AI/source services. Never place secret API keys in a public GitHub repository.

Educational content is introductory and may not reflect every current country-specific requirement. Verify applicable requirements against current official authority guidance and qualified professionals before workplace use.

## Publish with GitHub Pages
1. Download and extract the ZIP.
2. Open your GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload `index.html` (replace the old one).
5. Commit the change.
6. If GitHub Pages is already enabled, wait for deployment and refresh the website.

The website is a single HTML file and does not need a build step.
